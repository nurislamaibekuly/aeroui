What is aeroui?
Black & white, dependency-free UI components for the web. Vanilla CSS + ES modules.
How do I use it?
Link the stylesheet, add the script tags, and use the HTML classes. No build step required.
Is it accessible?
Yes. Native elements like checkbox, range, dialog, and details/summary are used throughout.
